## 🧠 Logique de recommandation automatique dans le rapport

À la fin de chaque bilan, en fonction des **axes activés** (score ≥ seuil), 2-3 produits sont automatiquement recommandés.

```
RÈGLES DE RECOMMANDATION
─────────────────────────────────────────────────────────
axe.intest >= 5         → Akkermansia + Probiotiques + L-glutamine
axe.hormon >= 5 (femme) → Pack Hormones (Mg + B6 + DIM + Ω3)
axe.peau   >= 5         → Pack Peau (Zn + Ω3 + D3+K2 + Curcumine)
axe.inflam >= 5         → Ω3 rTG + Curcumine BCM-95
axe.histam >= 5         → Quercétine + Vit C + DAO
axe.detox  >= 5         → NAC + Chardon-Marie (futur)
axe.carence_D souvent   → Vit D3+K2 quasi systématique
acne.machoire == true   → Zn + Myo-inositol + Berbérine
sommeil.reveils == true → Mg bisglycinate + Glycine + Magnesium
```

→ **Chaque rapport génère naturellement 2-3 ventes potentielles**.
