# LifeMicroNut Pro — Modèle B2B pour pros de santé

> **Concept** : équiper les pros de santé (médecins généralistes, naturopathes, sage-femmes, ostéopathes, micronutritionnistes, pharmaciens praticiens) de **nos questionnaires + bilans** comme outil de consultation. Abonnement mensuel + commission par rapport généré.

---

## 1 — Pourquoi cette offre

### Le besoin côté pro
- Beaucoup de pros de santé (en particulier naturopathes / micronutritionnistes / sage-femmes) **n'ont pas d'outil structuré** pour interroger leurs patients en profondeur.
- Les bilans actuels sont :
  - Sur papier (perte de temps, illisibles)
  - Faits « à la louche » en consultation
  - Sans plan d'action structuré derrière
- Beaucoup n'osent pas demander des analyses complémentaires faute de **trame médicalement défendable**.

### Notre proposition
LifeMicroNut Pro = **un cabinet en ligne complémentaire** pour pros de santé :
- Accès aux questionnaires LifeMicroNut en marque blanche
- Génération de bilans personnalisés pour leurs patients
- Liste d'analyses biologiques à demander → **outil de confiance avec le médecin traitant**
- Dashboard de suivi des patients (anonymisé/pseudonymisé)
- Mise à jour continue des contenus selon les avancées scientifiques

### Différence avec le tunnel consommateur (B2C)
| | B2C (lifemicronut.com) | B2B (Pro) |
|---|---|---|
| Cible | Le patient lui-même | Le praticien qui équipe ses patients |
| Prix | 19,90 € / bilan | Abonnement mensuel + bilan à prix réduit |
| Marque | LifeMicroNut visible | Co-brandé ou marque blanche partielle |
| Suivi | Aucun (one-shot) | Dashboard pluri-patients dans le temps |

## 4 — Tarification (proposition initiale, à A/B tester)

| Tier | Mensuel | Annuel (-20%) | Coût marginal bilan |
|------|---------|---------------|---------------------|
| **Essentiel** | **49 € HT / mois** | 470 € HT / an | 9,90 € par bilan |
| **Pro** | **99 € HT / mois** | 950 € HT / an | 5,90 € par bilan |
| **Premium** | **199 € HT / mois** | 1 910 € HT / an | 2,90 € par bilan |

### Justification psychologique des prix
- 49 € = inférieur au seuil de friction d'achat (vs 99 € qui demande justification).
- 99 € = sweet spot pour un naturopathe qui voit 5+ patients / semaine et veut un outil pro.
- 199 € = pour cabinets multi-praticiens, pharmacies, instituts.

### Pourquoi le pro paie au lieu de juste prendre une commission
- **Modèle Saas + marge** plutôt qu'affiliation pure → revenu récurrent prévisible pour LMN
- **Engagement** : le pro qui paie utilise vraiment l'outil. L'affiliation passive ne convertit pas.
- **Statut** : le pro est un partenaire actif, pas un revendeur. Plus de valeur perçue.

### Test alternatif (à benchmarker)
- Modèle « pay-per-use » : 0 € abonnement + 15 € HT par bilan généré. Plus simple à vendre, plus difficile à fidéliser.

### Première offre de lancement (incentive)
- **3 mois gratuits** pour les 100 premiers inscrits → constitue la première communauté pro
- Engagement annuel obligatoire au-delà des 3 mois gratuits

## 5 — Modèle économique

### Hypothèse réaliste an 1
| | Nb pros | ARPU mensuel | MRR |
|---|---------|-------------|-----|
| Essentiel | 50 | 49 € | 2 450 € |
| Pro | 25 | 99 € | 2 475 € |
| Premium | 5 | 199 € | 995 € |
| **TOTAL** | **80** | | **5 920 € / mois = 71 040 € / an MRR récurrent** |

Sur les bilans générés (volume secondaire, marge faible mais alimente le moteur) :
- Si chaque pro génère en moyenne 8 bilans / mois × 80 pros = 640 bilans / mois
- Marge moyenne par bilan : ~3 € (selon tier)
- Soit **~1 920 € / mois** complémentaire = **~23 000 € / an**

**Total Pro an 1 : ~95 000 € HT**

### Hypothèse an 2 (avec push commercial + réseau)
- 300 pros actifs → ~250 k€ / an MRR
- 2 000+ bilans / mois → ~70 k€ / an de bilans
- **Total an 2 : ~320 k€ HT**

→ La marge Pro **complète et stabilise** la marge B2C dans la trajectoire 1M€.

## 7 — Considérations légales / RGPD

⚠ **À VALIDER PAR UN AVOCAT SANTÉ AVANT LANCEMENT.**

### Point 1 : Statut des questionnaires
Les questionnaires LifeMicroNut sont des **outils d'orientation**, pas des dispositifs médicaux. Cela doit être :
- Explicite sur chaque bilan (« outil d'orientation, ne se substitue pas à un avis médical »)
- Cohérent dans la communication pro
- Documenté dans les CGV Pro

### Point 2 : Hébergement des données
Si le dashboard Pro stocke des **données de santé pseudonymisées** :
- → exigence d'**hébergement HDS** (Hébergeur de Données de Santé certifié)
- Solutions possibles : OVH HDS, AWS HDS, Scaleway HDS, Outscale
- Coût additionnel à anticiper : +200-500 €/mois selon volumétrie

**Phase 1 (Pilote 10 pros)** : pas de stockage nominatif, juste génération de PDF + code praticien. **Pas besoin de HDS.**
**Phase 2+** : si dashboard pluri-patients avec historique, **HDS obligatoire**.

### Point 3 : Responsabilité civile professionnelle
- LMN ne se substitue jamais à la consultation médicale
- Le pro reste **seul responsable** de son interprétation et de ses conseils
- Mention explicite dans les CGV Pro
- Assurance RC pro de LMN à vérifier (couverture outil numérique)

### Point 4 : Code de déontologie
Pour les médecins (Code de déontologie médicale, art. R.4127) : interdiction de **publicité directe**. Notre offre Pro ne doit donc pas être présentée comme un argument commercial à mettre en vitrine, mais comme un outil interne de travail.

## 9 — Risques identifiés & mitigations

| Risque | Probabilité | Impact | Mitigation |
|--------|-------------|--------|------------|
| Pro qui s'approprie l'outil sans payer | Moyenne | Moyen | Code praticien dans l'URL, suivi générations |
| Vente du PDF à un patient à 50 € sans nous redonner notre part | Faible | Faible | Le pro fait son métier, on accepte sa marge |
| Concurrent qui copie l'outil | Élevée à terme | Moyen | Vitesse d'exécution + qualité scientifique (cours micronutrition Assiya) |
| RGPD / HDS non conforme | Élevée si pas anticipé | Très élevé | Avocat dès phase 2, HDS quand stockage nominatif |
| Manque d'engagement pro après inscription | Moyenne | Moyen | Onboarding humain, webinaires mensuels, communauté |
| Inertie commerciale (cycle de vente pro long) | Élevée | Moyen | Offres gratuites incentivées + témoignages forts |
